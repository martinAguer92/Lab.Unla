# Lab.Unla
Abra Powershell/Bash/Terminal y navegue hasta la carpeta del proyecto.
Ejecutar python -m venv .venv para crear venv.
Ejecuta este comando .venv/Scripts/activate para activar venv en Windows.
Ejecutar pip install -r requirements.txt para instalar las bibliotecas desde el archivo de requisitos.
Ejecutar fastapi runpara ejecutar la aplicación en localhost y puerto predeterminado (8000).
Abre tu navegador y ve a localhost:8000/docs para acceder a la documentación de Swagger.
